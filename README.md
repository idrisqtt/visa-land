# Visa Land

Адаптивный сайт авторских путешествий по Японии, Южной Корее и другим странам.

## Локальный запуск

```bash
python3 -m http.server 4173 --directory dist
```

После запуска откройте `http://localhost:4173`.

## Развёртывание на Vercel

Проект не требует установки зависимостей или сборки. Конфигурация в `vercel.json`
указывает Vercel публиковать содержимое каталога `dist`.

1. Импортируйте этот GitHub-репозиторий в Vercel.
2. Framework Preset: `Other`.
3. Build Command: оставить пустым.
4. Output Directory уже задан как `dist`.

Основной контент туров, дат и FAQ находится в `dist/app.js`.
